# MagicConverter 아이콘

`magic_converter-tool.svg`는 이 프로젝트를 위해 직접 작성한 원본 벡터다. 겹친 문서와 별이 달린 마술 지팡이로 문서 변환을 표현한다. 외부 그림, 로고, 아이콘 팩 및 글꼴 파일을 사용하지 않았다.

`magic_converter-tool.ico`는 같은 벡터를 Windows에서 쓰는 여러 크기로 렌더링한 파일이다. `python tools/build/generate_icon.py --render`로 다시 만들 수 있다. 두 파일에는 프로젝트의 [AGPL-3.0-or-later](../LICENSE) 라이선스가 적용된다.
