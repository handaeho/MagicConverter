# MagicConverter 3.0.5 macOS 수정 배포

기존 macOS 배포에서 빠졌던 Windows의 드래그 휠과 설정·자동화 기능을 복원한 배포입니다. 태그는 `v3.0.5-macos.2`, 앱 빌드 번호는 `30502`입니다. Windows 3.0.5 배포 파일은 그대로 유지합니다.

- Finder의 Shift 변환 휠과 Control 빠른 작업 휠, 한국어 휠 글자 영역 제한.
- 브라우저 이미지·원시 이미지·파일 약속 드래그와 웹 입력 처리.
- 앱·Dock·메뉴 막대 아이콘, 오른쪽 아래 파일별 진행창과 대기 작업 처리.
- 클릭으로 편집하는 고급 설정·프리셋·휠 구성, 경로 복사와 Terminal 열기.
- 폴더 감시 규칙, 결과 기록·상세 결과, 설정 가져오기·내보내기와 백업 복구.
- CLI·MCP, 같은 사용자의 로컬 요청·취소·중단 후 재시도 처리.
- FFmpeg·FFprobe, Qt, MuPDF, PDFium, rhwp, HEIC/AVIF 엔진과 대체 글꼴 포함. Python·Homebrew 별도 설치 불필요.
- 구형 PPT와 인쇄 설정 PDF를 위한 LibreOffice 엔진 포함. 별도 문서 프로그램 없이 오프라인 출력 가능.
- Mac PDF 출력의 공백·콜론 문자 매핑과 선택적 영문 합자를 수정해 원문 검색·복사 보존.
- PKG 설치 마법사와 앱 메뉴의 제거 확인 창. 원본·결과·설정·기록 보존.

## 검증 범위

같은 합성 입력과 Windows 3.0.5의 변환 목록을 기준으로 Apple Silicon·Intel에서 검사합니다. Windows의 7,290개 선택 질의와 828개 실변환 경로를 비교하고, 성공 여부와 출력 파일 수·이미지 크기·프레임 수·PDF 페이지·검색 문자·ZIP 구성 차이를 배포 전에 차단합니다. 빌드 환경의 Homebrew 파일에 접근하지 못하게 한 오프라인 실행도 포함합니다.

Finder와 WebKit의 실제 드래그, 원시 이미지와 파일 약속 드래그, 설정 UI에서 저장한 프리셋의 실제 변환, IPC 재요청·프로세스 재시작·감시 중복 방지, MCP 취소 후 다음 작업, PKG 설치와 앱 메뉴 제거를 검사합니다. DOCX → HWPX 사진 표와 PDF → 편집 가능한 PPTX의 기존 회귀 검사도 포함합니다.

자세한 결과와 해시는 [릴리스 자산](https://github.com/handaeho/MagicConverter/releases/tag/v3.0.5-macos.2)의 `verification.json`, `conversions-arm64.json`, `conversions-x86_64.json` 및 `office-arm64.json`, `office-x86_64.json`으로 제공합니다. 이미지의 픽셀 전체나 모든 실제 문서의 조판이 Windows와 동일함을 보증하는 검사는 아닙니다. 글꼴·코덱과 운영체제에 따른 출력 바이트 차이는 존재할 수 있습니다.

## 지원 조건

macOS 15 이상과 칩에 맞는 배포 파일이 필요합니다. 별도 문서 프로그램이 필요하지 않습니다. Windows의 Microsoft Office 인쇄와 Mac의 LibreOffice 인쇄는 프로그램·글꼴에 따른 조판 차이가 있을 수 있습니다. 구조화 자료의 표·배열 조건은 동일하게 적용합니다. PKG는 사용자 홈에 설치해 관리자 권한 없이 제거합니다. 문서 엔진을 포함하므로 이전 Mac 기본 패키지보다 용량이 큽니다.

유료 Apple Developer ID 서명과 공증은 없습니다. [설치·첫 실행·제거 및 지원 조건](../user/MACOS.md)을 확인하세요.
