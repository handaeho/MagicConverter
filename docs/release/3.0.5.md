# MagicConverter 3.0.5

- PDF → 편집 가능한 PPTX로 변환할 때 흐름도의 여러 도형에 있던 글자가 한 셀에 모이던 문제를 수정했습니다. 라벨을 원래 위치에서 각각 편집할 수 있습니다.
- 테두리가 일부 생략된 표의 제목 행과 열을 더 잘 인식합니다. 셀의 가운데 정렬과 원본 선을 보존하고, PowerPoint 기본 검은 테두리가 추가되는 문제를 수정했습니다.

복합 클리핑 등 일부 그래픽은 원본 모양을 유지하기 위해 그림으로 옮깁니다. Windows x64 설치·제거 실행 파일에는 코드 서명이 없습니다.
