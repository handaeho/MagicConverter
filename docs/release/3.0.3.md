# MagicConverter 3.0.3

- 변환 휠과 빠른 액션 휠의 한글 글자가 칸 경계를 넘지 않도록 배치했습니다. 긴 이름은 해당 칸에 마우스를 올리면 휠 가운데에서 확인할 수 있습니다.
- 화면 오른쪽 아래에 처리 중인 파일 이름과 완료 개수를 표시합니다. 짧은 작업도 완료 표시가 잠시 남으며 진행창은 키보드 포커스와 마우스 클릭을 가로채지 않습니다.
- Word를 HWPX나 HWP로 변환할 때 표 셀 안의 글자가 테두리를 넘는 문제를 수정했습니다. 자동 높이와 최소 높이 행은 글자 크기와 줄 수를 반영하고, 셀의 가운데 배치와 글꼴별 공백 너비를 유지합니다.
- 제거 마법사는 실행 중인 MagicConverter와 잠긴 파일을 삭제 전에 확인합니다. 막힌 이유를 표시하며 앱을 종료하거나 파일 상태를 바꾼 뒤 같은 화면에서 **다시 시도**할 수 있습니다.

3.0.0~3.0.2에서 업데이트하면 기존 설정과 작업 기록을 이어서 사용할 수 있습니다. [설치 및 업그레이드](../user/PUBLIC_WINDOWS.md) · [제거 안내](../user/UNINSTALL_WINDOWS.md)
