# Windows x64 installer sources for MagicConverter 3.0.0

The package includes the Rust application and installer, dynamically loaded Qt, MuPDF, PDFium and HEIF libraries, and separate FFmpeg and rhwp executables. No Python runtime is installed. The application and installer sources, Cargo registry sources, and MSYS2 sources are available from the 3.0.0 release.

The packaged FFmpeg, FFprobe, Qt, MuPDF and Microsoft runtime files come from the pinned archives on the 2.2.39 release. Download the three archives named in [the runtime preparation script](../../tools/build/prepare_rust_release_runtime.py). That script verifies the archive SHA-256 values and records the hash of each selected file in the installer. The published native source archive contains the source, build configuration and patches for FFmpeg and its codecs, Qt, MuPDF and rhwp. PDFium is unchanged from 2.2.39. The Windows runtime files carry the Microsoft terms included with the installer. [2.2.39 native sources and build instructions](WINDOWS_INSTALLER_SOURCE.md) · [Pinned 2.2.39 archives](https://github.com/handaeho/MagicConverter/releases/tag/v2.2.39)

The 3.0.0 MSYS2 source archive includes the source and packaging files for each included HEIF and AVIF dependency. Each binary's pinned SHA-256 is in `rust_heif_runtime.json`. The source inventory records the matching `PKGBUILD` hashes from the original binary packages. Use the source archive's package recipes to rebuild the libraries for UCRT x64. The Cargo archive contains the registry packages and license files for the application's and installer's Cargo locks.

Use the Windows x64 MSVC Rust toolchain, Visual Studio C++ build tools and the Windows SDK, then follow [the Rust build instructions](../development/BUILD.md). Pass the directory with the three verified 2.2.39 inputs as `-PublishedRuntimeAssets` to `build.ps1`. The Qt and MuPDF bridge sources are under `rust/magic-converter/native`. Python is used during build preparation.

To rebuild or debug the dynamic libraries, close MagicConverter and replace the files in a copy of the installed `vendor/qt`, `vendor/mupdf`, `vendor/pdfium` or `vendor/heif` directory. Retain the expected file names, entry points and compatible dependencies. The Qt platform plugin is under `vendor/qt/plugins/platforms`. The installed program accepts locally replaced compatible libraries. The installer validates the contents of its embedded archive during installation. Use `magic_converter-windows-setup.exe bundle --payload <directory> --output <new-installer>` with a staged payload to package a modified build.

FFmpeg uses GPLv3 or later. Qt is used under its applicable LGPLv3 terms. MuPDF is used under the AGPL terms. The license and notice files for the other components are included with the corresponding libraries and source packages.
