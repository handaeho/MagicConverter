# MagicConverter 3.0.4

- DOCX를 HWPX로 변환할 때 사진이 든 긴 표가 쪽 아래에서 잘리는 문제를 수정했습니다. 표가 다음 쪽으로 이어지며, Word에서 반복하도록 지정한 제목 줄은 다음 쪽에도 표시됩니다.
- Word의 고정 줄 높이 때문에 셀 글자가 윗선에 붙던 문제를 수정했습니다. 직접 지정한 셀 정렬과 표 스타일의 정렬을 반영하고, 그림과 빈 문단의 높이도 원본에 가깝게 계산합니다.

기존 3.0 설정과 작업 기록은 업그레이드 후에도 사용할 수 있습니다. Windows x64 설치·제거 실행 파일에는 코드 서명이 없습니다.
