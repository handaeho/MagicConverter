# MagicConverter 3.0.0 Windows x64

Windows x64용 MagicConverter를 Rust로 전환했습니다. 기존 Python 2.2.39와 같은 입력으로 변환 결과를 비교하고, 오프라인 설치·업그레이드·제거까지 검증했습니다.

**설치** · `MagicConverter-3.0.0-Windows-x64.zip`을 풀고 `magic_converter-setup.exe`를 실행하세요. 설치본에 변환 엔진을 포함합니다. 2.2.39에서 설정, 기록과 폴더 감시 규칙을 가져옵니다. Windows ZIP은 91.9MB, 설치 후 파일은 289.9MB입니다. 설치·제거 EXE는 Authenticode 서명이 없습니다.

## 검증 결과

- 대표 변환 828개를 실행했습니다. 양쪽 성공 813개, 양쪽 거부 10개, Rust만 성공 5개였습니다. 추가 유효 입력 14개는 양쪽에서 성공했습니다.
- 이미지 118개, 직접 미디어 258개, PDF 13개, 웹 입력 11개를 별도로 확인했습니다. 오디오→동영상 48개는 디코딩한 소리와 정지 화면을 대조하고, 화면 길이가 원음에서 한 프레임 이내인지 확인했습니다. 차트 데이터를 수정한 PPTX를 PowerPoint에서 PDF로 내보내 결과를 확인했습니다. 한글 2024에서 저장한 입력을 HWPX와 구형 HWP에서 각각 PDF로 변환해 수정한 글자의 검색과 선택을 확인했습니다.
- 네트워크를 끈 Windows 11 Sandbox에서 GUI·CLI·MCP, OLE 드래그, 사용자 지정 설치 경로, 업그레이드, 재설치와 제거를 확인했습니다. 이 설치 시험은 단일 비교입니다.

## 성능

같은 Windows 호스트에서 워밍업을 제외한 3회 중앙값입니다. 시간은 CLI 실행부터 출력 완료와 프로세스 종료까지 포함합니다.

| 작업 | Python 2.2.39 | Rust 3.0.0 |
| --- | ---: | ---: |
| 파일 6개 원본 복사 | 0.83초 | 0.06초 |
| 이미지 5개 → PNG | 2.96초 | 0.18초 |
| 이미지 3개 → AVIF | 2.25초 | 0.21초 |
| PDF → 편집형 PPTX | 2.89초 | 0.23초 |
| DOCX·XLSX·PPTX → PDF | 13.32초 | 7.68초 |
| 동일 FFmpeg, WAV·MP3 → FLAC | 1.10초 | 0.23초 |
| 동일 FFmpeg, MP4·WAV → WebM | 0.92초 | 0.23초 |
| 기록 100건이 있는 프로필에서 파일 복사와 기록 | 0.82초 | 0.09초 |
| 동일 FFmpeg, 720p MP4 → WebM (4회 중앙값) | 13.82초 | 12.72초 |

별도 868만 셀 XLSX 시험에서 Python은 190.9초(1회), 같은 Rust XLSX 처리 코드의 앞선 반복 측정 중앙값은 18.4초였습니다. 공개 설치본에서 출력 PDF의 SHA-256을 다시 대조했습니다.

편집형 PDF→PPTX는 규격이 다른 PDF 페이지를 한 가지 슬라이드 크기에 맞춥니다. 일부 PDF 합성 영역은 그림으로 들어갑니다. 편집과 조판의 한계는 변환 가이드에 설명합니다.

`verification.json`에는 테스트와 성능 수치를, `build-manifest.json`과 `SHA256SUMS.txt`에는 파일 해시를 담았습니다.
