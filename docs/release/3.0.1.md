# MagicConverter 3.0.1

- 일반 설정의 회색 텍스트 배경을 제거하고 **변환할 파일 고르기** 버튼으로 원본 선택 기능을 명확히 했습니다.
- 고급 설정은 숫자와 결과 파일 이름을 목록에서 고르고, FFmpeg와 저장 폴더는 선택 창에서 지정할 수 있습니다. 글자가 잘리지 않도록 창 배치를 정리했고 기존 사용자 지정 파일 이름도 유지합니다.
- 일반 설정과 고급 설정에 한국어 마우스 도움말을 추가했습니다.
- Windows 키나 Alt 키 조합을 사용하는 동안, 또는 Windows 캡처 도구에서 영역을 고르는 동안 변환 휠이 나타나지 않도록 했습니다.

3.0.0 사용자는 3.0.1 설치 후 기존 설정과 작업 기록을 계속 사용할 수 있습니다. [설치 안내](../user/PUBLIC_WINDOWS.md) · [제거 안내](../user/UNINSTALL_WINDOWS.md)
