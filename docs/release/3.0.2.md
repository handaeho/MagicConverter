# MagicConverter 3.0.2

- Windows 설치 마법사에서 환영 화면, 라이선스 동의, 설치 위치 선택, 진행률, 완료 화면을 복원했습니다. 설치 파일을 더블클릭하면 터미널 없이 마법사가 열립니다.
- **찾아보기**로 상위 폴더를 선택할 수 있고, 설치하기 전에 실제 설치 경로를 확인할 수 있습니다. 설치가 끝나면 **MagicConverter 실행**으로 앱을 열 수 있습니다.
- 제거 마법사에서 설치 위치와 진행률을 확인할 수 있습니다. 사용자 설정과 변환 기록, 원본과 결과 파일은 보존됩니다.
- 오프라인 설치와 `--quiet`를 사용한 무인 설치·제거를 계속 지원합니다.

3.0.0과 3.0.1에서 업데이트하면 기존 3.0 프로필을 이어서 사용할 수 있습니다. [설치 및 업그레이드](../user/PUBLIC_WINDOWS.md) · [제거 안내](../user/UNINSTALL_WINDOWS.md)
