# MagicConverter 2.2.32 제거

1. 실행 중인 변환을 마치고 알림 영역에서 MagicConverter를 종료합니다. CLI나 폴더 감시를 사용 중이면 함께 종료합니다.
2. 설치할 때 받은 ZIP을 풀고, 다운로드 폴더처럼 설치 폴더 밖에서 `Uninstall.exe`를 실행합니다. [Windows ZIP 다시 받기](https://github.com/handaeho/MagicConverter/releases/download/v2.2.32/MagicConverter-2.2.32-Windows-x64.zip)
3. 확인 창에 표시된 설치 위치와 제거 항목을 확인하고 **예**를 누릅니다.

설치 프로그램은 실제 설치 위치를 기록합니다. 예를 들어 설치할 때 `D:\Apps`를 선택했다면 제거 도구는 `D:\Apps\magic-converter`의 설치 표식을 확인합니다. 이전 방식으로 설치한 경우에는 기존에 기록된 경로를 사용합니다.



이 제거 도구는 관리자 권한이나 인터넷 연결 없이 실행됩니다. 파일이 사용 중이라는 안내가 나오면 해당 앱을 종료한 뒤 다시 실행하세요.
